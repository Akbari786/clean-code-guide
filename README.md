### Englisch:

**Clean Code – A Practical Guide**

This repository documents practical Clean Code principles with real-world examples in Java. No theory, no fluff – just before-and-after comparisons that show why clean code matters and how to write it.

The project grows daily. Each day brings a new topic:
- Meaningful variable names
- Focused methods (Single Responsibility)
- Function arguments and object patterns
- Error handling
- Class design
- And more...

**Perfect for:** Junior developers, code reviews, job applications, and anyone committed to writing better code.

One commit at a time, getting better every day. 📚

### Deutsch:

**Clean Code – Praktische Leitfaden**

Dieses Repository dokumentiert praktische Clean Code Prinzipien mit echten Beispielen in Java. Keine theoretischen Konzepte – nur Vorher-Nachher Vergleiche, die zeigen, warum sauberer Code wichtig ist und wie man ihn schreibt.

Das Projekt wächst täglich. Jeder Tag bringt ein neues Thema:
- Aussagekräftige Variablennamen
- Fokussierte Methoden (Single Responsibility)
- Function Arguments und Object Patterns
- Fehlerbehandlung
- Klassen-Design
- Und mehr...

**Perfekt für:** Junior Developers, Code Reviews, Jobbewerbungen und alle, die sauberer coden wollen.

Commit für Commit, jeden Tag ein Stück besser. 📚
